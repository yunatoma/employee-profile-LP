# ひとナビ LP プロジェクト

サービス名「ひとナビ」（社員プロフィール・スキル・稼働状況を組織で一元管理するSaaS）のLPを制作するプロジェクト。

**Why:** デモ誘導とポートフォリオ掲載が主目的。価格表より機能・技術構成・実装品質を見せる構成。

**How to apply:** 業務SaaS寄りのトーン。落ち着いた信頼感を優先。過度にポップな表現は避ける。

## LPセクション構成

1. Hero — キャッチコピー + CTA（デモを見る / GitHubを見る）+ スクリーンショット
2. Problem — スプレッドシート散在・検索しづらい・情報が古い・アサイン検討に時間
3. Solution — 一元管理・絞り込み検索・社員自身が更新・申請フロー・AIチャット
4. Features — プロフィール管理 / ダッシュボード / 組織・権限管理 / 申請管理 / AI人材検索
5. Use Cases — 実際の利用シナリオ4つ
6. Security / Architecture — Googleログイン・組織データ分離・Firebase/CloudRun・権限分離
7. CTA — デモを試す / GitHubで見る / 導入相談する

## 技術スタック（LP側）

- Astro v6 + TypeScript (strict)
- Tailwind CSS v4
- Vercel adapter（静的出力）

## プロダクト技術スタック（本体）

React 19 / Redux Toolkit / Tailwind CSS v4 / Firebase Auth / Firestore / Firebase Storage / Cloud Run + Express.js / Recharts / Gemini API
